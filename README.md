# GitHub Aura Scanner 🌌

A simple tool to check your GitHub profile's "Aura" based on your account stats.

[**Live Demo**](https://git-aura-check.lovable.app/)

## ⚡ Features
- **Profile Scan:** Enter any GitHub username to get a rank.
- **Real-time Stats:** Pulls data directly from the GitHub API.
- **Aura Types:** Categorizes users into different personas (e.g., The Architect, Rising Star).
- **Clean UI:** Dark-mode dashboard with neon accents.

## 🛠️ Built With
- **Lovable** (Frontend)
- **GitHub REST API** (Data)
- **Tailwind CSS** (Styling)

## 🚀 How to use
1. Visit the live link.
2. Enter a GitHub username.
3. See the results instantly.
